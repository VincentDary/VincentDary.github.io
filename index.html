Projects

  • Fiit: Firmware Instrumentation and Introspection Tools

    Fiit aims to provide a comprehensive toolbox for firmware instrumentation and dynamic analysis in both emulated and physical environments. This project targets exotic CPU architectures and bare-metal or real-time operating system. This project provides interfaces for prototyping emulation environments with advanced software introspection capabilities. On the one hand, these interfaces enable the development of advanced rehosting strategies, such as partial hardware modeling and Hardware Abstraction Layer (HAL) replacement. On the other hand, it provides dynamic analysis modules that enable advanced characterization of software/hardware interactions, function call interception, and access to system data structures, making it possible to build complex dynamic introspection rules.

  • OFDB: Open Firmware Dataset Builder

    This project seeks to promote and enable reproducible results in the field of firmware analysis research. It provides a reproducible way to build a firmware image dataset based on full or partial open source firmware. The repository provides material (tools and sources code), scripts and makefiles to build firmware images, and standardised metadata about each firmware image.

  • Python CMSIS-SVD Library

    A CMSIS-SVD spec Python parser and serializers. The parser is able to read in an input CMSIS-SVD file and provide a Python data structures containing the information from the SVD. This frees the developer (you) from having to worry about the SVD XML and each vendor's little quirks.

Tiny Projects

  • PolyAsciiShellGen: Caezar ASCII Shellcode Generator

    PolyAsciiShellGen is an experimental ASCII shellcode generator written in C. This program is based on the Riley 'Caezar' Eller's technique to bypass MSB data filters, for buffer overflow exploits, on Intel x86 platforms.
